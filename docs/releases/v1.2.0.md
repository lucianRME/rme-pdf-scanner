## What's changed

- PageHarbor is now **RME: PDF & Document Scanner** — the same privacy-first document scanner with a new name.
- Updated in-app branding, About and privacy presentation, documentation, and editable branding assets.
- Included release packaging optimizations.
- Existing installations retain the same app identity, with compatible user data and settings.

## Upgrade

Existing PageHarbor users can upgrade normally when the update is available for their installation source. User data and settings remain compatible.

This is the GitHub release. Google Play rollout will be handled separately after the store listing and graphics are updated.

Release artifacts: signed Android APK and Android App Bundle (AAB).
