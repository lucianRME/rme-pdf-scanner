# RME: PDF & Document Scanner

RME is a free, privacy-first, open-source Android document scanner developed by SynapseWorks.

## Features

- Document scanning and PDF import
- On-device multilingual OCR
- Searchable PDFs
- Local document library
- PDF merge, split, and compression
- Share-Safe document redaction
- Two-sided ID and card copying
- Optional encrypted backups
- Optional device authentication

## Privacy

- No RME account required
- No advertisements
- No RME analytics or tracking
- No RME-operated document backend
- Local document processing
- No `INTERNET` permission requested by RME

RME uses Google ML Kit and components delivered through Google Play services. Scanner resources and optional OCR models may be downloaded or updated by Google Play services, and ML Kit may send technical diagnostics under Google's practices.
