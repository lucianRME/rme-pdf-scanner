# RME: Private PDF Scanner v1.8.0

26 November 2026 · version code 23 · Android 8 and later

RME 1.8.0 turns a paper document into a file you can edit, sign or share, with document processing on your Android device.

- **Scan and clean up.** Capture stacks of pages, split book spreads, straighten tilted photos and reduce shadows. Review both sides of an ID in one guided flow.
- **Check the words.** OCR follows table rows more reliably. Tap a passage to compare it with the original, or review spelling offline.
- **Take your work further.** Export supported pages as editable DOCX, receipt reports as XLSX, tables as CSV and slides as PPTX. Fill compatible PDF forms, annotate pages, add a handwritten signature or password-protect an exported copy.
- **Import large camera photos.** Fixed the working-image limit that caused ordinary high-resolution photos to be refused. Verified with 13 MP and 48 MP test photos. [Issue #6](https://github.com/lucianRME/rme-pdf-scanner/issues/6).

### Installing this release

Download `rme-pdf-scanner-v1.8.0.apk` for Android 8 or later. Existing GitHub installs can update in place. Play and GitHub use different signing certificates. If you already use the Play edition, use Play for updates to preserve your local library.

The APK includes the translation runtime for supported 64-bit ARM devices running Android 15 or later. Google Play delivers language packs for the Play edition. The GitHub APK contains no language models and supports advanced import of compatible local packs. Office-format exports are included. Importing Office files to convert them to PDF is unavailable in this build.

The [checksums](https://github.com/lucianRME/rme-pdf-scanner/releases/download/v1.8.0/SHA256SUMS.txt) cover both the APK and the [third-party notices](https://github.com/lucianRME/rme-pdf-scanner/releases/download/v1.8.0/rme-pdf-scanner-v1.8.0-notices.zip). Google Play review was pending when this GitHub release was prepared.
