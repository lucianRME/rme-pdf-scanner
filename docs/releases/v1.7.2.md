# RME: Private PDF Scanner v1.7.2 release notes

Version: **1.7.2 / code 21**. Release date: 28 October 2026.
Published on [GitHub](https://github.com/lucianRME/rme-pdf-scanner/releases/tag/v1.7.2)
and [SourceForge](https://sourceforge.net/projects/rme-pdf-scanner/files/v1.7.2/).
Google Play publication is separate; no Play upload was performed for this release.
See [release validation](v1.7.2-validation.md).

- Updated the installed application name to **RME: Private PDF Scanner**.

- Kept **RME PDF Scanner** as the compact launcher name.

The application ID and data formats are unchanged. No document migration is introduced.

documentelor.
