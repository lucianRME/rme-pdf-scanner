# RME Backup v1 golden metadata

All values are synthetic. `manifest.json` and the JSONL streams define one nested 21-page document
with a retained source PDF. The page and source hashes deliberately describe deterministic bytes
generated by tests rather than committed user-like binaries. `unsupported-required-feature.json`
must be rejected before extraction or library mutation.

The golden metadata demonstrates that the format has no 20-page archive limit and that unknown SAF
metadata stays `null`; it does not assert a timestamp or byte size the provider did not expose.
