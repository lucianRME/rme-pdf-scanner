# RME PDF Scanner v1.7.1 release notes

## English

- More reliable deletion of saved documents.
- Improved recovery when document deletion is interrupted.
- Safely identifiable leftover private document files from earlier versions are now cleaned up
  automatically.

## Română

- Ștergere mai fiabilă a documentelor salvate.
- Recuperare îmbunătățită atunci când ștergerea unui document este întreruptă.
- Fișierele private rămase din versiunile anterioare și care pot fi identificate în siguranță sunt
  acum curățate automat.
