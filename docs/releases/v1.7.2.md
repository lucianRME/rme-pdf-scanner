# RME: Private PDF Scanner v1.7.2 release notes

Status: **unreleased candidate**, version 1.7.2 / proposed code 21. These are proposed publication
notes, not a release announcement. See [validation and owner gates](v1.7.2-validation.md).

## GitHub — English

- Updated the installed application name to **RME: Private PDF Scanner**.
- Aligned About, app-sharing, and support identity with the official product name.
- Kept **RME PDF Scanner** as the compact launcher name.

The application ID and data formats are unchanged. No document migration is introduced.
A production-channel upgrade with matching signing must still be verified before publication;
these notes do not claim a completed user-data compatibility test.
