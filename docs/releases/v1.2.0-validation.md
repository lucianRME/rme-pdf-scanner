# v1.2.0 release validation

Release: **RME PDF Scanner v1.2.0**, Android version name `1.2.0`, version code `13` (previously `1.1.0` / `12`). Application ID and namespace remain `org.synapseworks.pageharbor`.

## Build and automated checks

- `./gradlew assembleDebug assembleReleaseVerification assembleReleaseForPlay bundleReleaseForPlay test lint assembleDebugAndroidTest --offline`: passed.
- Unit tests: 171 passed per variant (debug, release, releaseVerification), 513 executions total, no failures or skips.
- Lint: no errors; 28 warnings and one hint. No rules or tests disabled.
- Full instrumentation suite on Samsung SM-S938B / Android 16: **116 passed**, no failures or skips.
- The preceding disposable Android 12 emulator run had 115 passes and one failure: `ActiveOperationInterruptionTest.pausedSearchablePdfCompletesWithOneDestinationRequestAfterBackgroundAndForeground` timed out waiting for the destination request. Publication stopped at that point. The owner then requested a retry on the attached physical device; the entire suite, including that test, passed without test or application-behavior changes. The emulator timeout is recorded, not attributed to a proven cause.

## Physical-device test method

The phone already held the production-signed 1.1.0 app. To preserve the installed application and its data, temporary copies of the debug app and test-runner APKs were signed locally with the existing production key, then installed using `adb install -r`. The full suite ran through `adb shell am instrument -w -r org.synapseworks.pageharbor.test/androidx.test.runner.AndroidJUnitRunner`.

This required no repository signing-configuration change or app uninstall. These temporary debug artifacts are not GitHub release assets. The production 1.2.0 APK replaces the temporary test build after validation, and the test-only runner is removed.

## Artifact and compatibility checks

- The production APK and AAB expose version `1.2.0` / `13` and the existing application ID.
- APK signature verification and AAB signed-entry verification passed. Both use the same certificate as the previous v1.1.0 GitHub APK and the phone's existing installation.
- Production APK label is `RME: PDF & Document Scanner`; no INTERNET permission or debuggable flag is introduced.
- Production artifacts are rebuilt after the release commit so their embedded version-control metadata identifies that commit.
- Signing configuration, keys, package structure, persisted storage identifiers, provider authority, and repository identity are unchanged.
